# Msk104Master 接入

## 环境和检查

- 在 Windows 下以普通权限运行测试上位机，准备支持测试会话的新版 `Msk104Master.exe`、WebView2 Runtime 和匹配的 `msedgedriver.exe`。
- “测试环境”默认关闭 104 主站。启用后保存程序路径与主站等待时间，复用环境中填写的 EdgeDriver 路径。保存过旧主站路径的环境需要重新选择 `Msk104Master.exe`。
- “检查主站”使用当前填写的路径，可以在保存环境前执行，也可以在尚未设置 DSP 上位机时执行。启动副本前检查程序是否支持测试会话，再通过 EdgeDriver 读取独立临时副本的界面。完成、失败或取消后释放本次资源。协议连接和业务结果由用例验证。

## 独立会话

- 用例通过 `master104` fixture 按需启动独立主站副本，使用单独的 WebView2 数据目录和 EdgeDriver 会话。会话结束只清理本次启动的程序及驱动。
- AGC 用例从专用配置填写下位机 IP、104 端口和公共地址。通过界面连接，收到 STARTDT 确认后执行总召，确认总召终止后核对两个闭锁遥信初值。
- 短浮点直接执行通过主站的“遥调”界面发送。每个目标只提交一次，使用支持三帧取证的 `Msk104Master.exe`。测试上位机核对本笔请求、肯定确认和肯定终止的原始帧、地址、设定值及时间，之后再检查下位机业务反馈。详细步骤见 [AGC 增减闭锁验收](AGC增减闭锁验收.md)。

## 双端证据

- 同一个用例可以注册 DSP 上位机及主站会话。报告按来源关联步骤、截图、元信息和实际观察，保留各自的原始证据。
- 主站截图由该主站的 EdgeDriver 会话采集。截图失败保留缺失原因，业务异常、采集错误及环境前置条件失败分别记录。
- 用例失败先保留现场，再释放本次会话。不会重复发送失败或结果未知的遥调，也不会自动下发恢复目标。

“检查主站”只能验证 WebView2 和 EdgeDriver 接入。完整验收需要按专项配置运行 Windows 桌面用例，核对真实 104 收发和 DSP 状态。
