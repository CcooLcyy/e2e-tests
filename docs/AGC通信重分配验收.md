# AGC 通信重分配验收

在测试上位机选择“测试环境 → 运行与隔离 → 全新独立副本”，然后填写：

- “Modbus RTU”中的下位机 ModuleManager 地址、轮询周期和采集等待时限。下位机使用 IPv4 地址或可解析到 IPv4 的主机名，轮询周期最多 10000 毫秒。勾选下位机与 slaveSim 专供 AGC 通信重分配测试，按需填写 104 监听端口，默认 2404。
- “slaveSim 模拟器”中的管理页地址。模拟器需与下位机共享实际串口路径，且从空总线列表开始。
- “104 模拟主站”中的启用开关及支持短浮点三帧取证的 `Msk104Master.exe`。DSP 上位机和 WebView2 驱动路径使用“基础信息”中的配置。

使用专用设备。下位机的 DataCenter、ModbusRTU、AGC 和 IEC104 模块须可用。用例先读回数据总线连接目录、RTU 和 IEC104 连接列表、AGC 控制组及模拟器总线。若发现已有资源或读取失败，停止配置并保留现场。

保存环境后，到“测试执行”单独勾选“AGC 通信重分配”。该用例默认未勾选。运行后自动创建三台额定 200 kW 的模拟逆变器、RTU 量测与控制点、按通信状态筛选成员的 AGC 组，以及从 104 短浮点遥调到 AGC 总控点的路由。104 主站连接 ModuleManager 地址所用的同一主机，使用环境中填写的 104 端口。

| 阶段 | AGC 总目标 | 参与调节 | 每台下发目标 |
| --- | ---: | --- | --- |
| 三台通信正常 | 300 kW | 1、2、3 | 100、100、100 kW |
| 第三台抄读失败 | 300 kW | 1、2 | 150、150 kW |
| 第三台通信恢复 | 300 kW | 1、2、3 | 100、100、100 kW |

用例只在第一阶段通过 104 下发一次总目标，核对发送、肯定确认和肯定终止三帧。故障阶段把第三条 RTU 连接切到未占用的站号，等待它恢复轮询后读到通信异常，另外两条连接保持通信正常。用例核对 AGC 设定、slaveSim 收到的控制写入和功率反馈，并确认第三台保留原设定。切回原站号后再次核对三台分配。

创建的配置在用例结束后保留，失败时保留当时的站号、报文、步骤与各端截图，方便定位。再次运行前，请准备同样的专用空环境。
