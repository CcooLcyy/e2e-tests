# RTU 环境界面配置

环境页仅保留下位机 ModuleManager 地址、轮询周期和采集等待时限；slaveSim 管理地址沿用既有入口，并且须指向当前 DSP 对接的模拟器。基础采集与华为六路用例不再要求手填总线、串口、从站、寄存器或资源确认项。

具体配置在用例执行阶段通过 slaveSim 管理页面读取，必要时补充模拟资源，保存后确认生效。历史环境内的静态 RTU 字段兼容保留，但不参与执行，也不覆盖实际发现结果。不读取独立 `local/modbus-rtu.json` 或 `local/huawei-rtu.json`。详细行为、影响和验收范围见 [RTU运行时模拟器配置](RTU运行时模拟器配置.md)。

两类用例仍要求全新独立副本、有效的 DSP 和 slaveSim 连接入口。开始前只检查连接入口、模式及测试等待参数；执行阶段发现资源或配置失败时，保留前置失败与两端证据，不放宽业务断言。

本次不在本地运行构建或测试。界面更新需用户关闭旧测试上位机，再运行“启动测试上位机.cmd”，由现有启动器按需更新；仅刷新用例不能更新界面。真实串口可见性、配置生效及采集结果以用户运行原用例的报告为准。
