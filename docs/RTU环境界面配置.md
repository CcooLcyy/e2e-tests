# RTU 环境界面配置

在「测试环境」填写 DSP 上位机程序、EdgeDriver 和已提供的 slaveSim 入口。「Modbus RTU」配置采集等待时限，默认 300 秒，可填写 5～300 秒。

五条基础 RTU 用例自行从 slaveSim 发现或创建总线、设备和寄存器，并按用例要求设值。随后用读到的串口和站点参数在 DSP 上位机建立连接和点表。 [基础 RTU 流程](Modbus%20RTU双端采集测试.md)

华为六路 21 台验收自行准备专用模拟机群，再创建本例连接和点表。 [华为机群流程](华为21台六路RTU采集测试.md) [104 品质流程](Modbus%20RTU到104品质验收.md)

界面更新需关闭旧测试上位机，再运行「启动测试上位机.cmd」。实际采集结果以本次用户运行的报告为准。
