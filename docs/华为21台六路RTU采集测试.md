# 华为21台六路 RTU 采集测试

## 环境与目标

运行前准备六路串口与 21 台华为 V3 行为模型。第 n 路含站号 1 至 n，每台都有对应的已运行 DSP RTU 连接和 18 个采集点。按 [RTU 模拟环境与观察配置](RTU运行时模拟器配置.md) 填写专项观察文件。全局第 n 台使用直流可用功率 10+n kW、线电压 380+n V、频率 50 Hz、环境温度 25℃、效率 1，并关闭扰动。可区分的电压与可用功率用于发现串路和串站。

测试开始前安排下列工况顺序和观察窗口。每个工况保持到该轮 21 台观察完成。测试程序通过 DSP 上位机选择各台现有连接，通过 slaveSim 读取实际反馈。环境与工况由测试外部事先安排。未看到预定工况时按超时和最后观察报告失败。

| 顺序 | 工况 | 固定预期 |
| --- | --- | --- |
| 1 | 发电 | P 为 10+n kW，Q=0，PF=1。 |
| 2 | 有功调节 | 有功百分比为 10+n/10%，P 达到本机容量乘该比例，Q=0，PF=1。 |
| 3 | 无功调节 | 保持有功限值，Q 为正，PF 接近 0.9。 |
| 4 | 负无功调节 | 保持有功限值，Q 和 PF 均为负。 |
| 5 | 待机 | P=Q=三相电流=0，PF=1。 |
| 6 | 限电停运 | 恢复直流可用功率，有功限值为 0，P=Q=三相电流=0，PF=1。 |
| 7 | 恢复发电 | 恢复初始有功目标，Q=0，PF=1。 |

## 采集点目录

| 点位 | 点标识 | 零基地址 | 类型／倍率 |
| --- | --- | --- | --- |
| A/B/C 相电压 | voltage_a/b/c | 32069/32070/32071 | UINT16，0.1 |
| A/B/C 相电流 | current_a/b/c | 32072/32074/32076 | INT32，0.001 |
| 有功／无功 | active / reactive | 32080/32082 | INT32，0.001 |
| 功率因数 | pf | 32084 | INT16，0.001 |
| 状态字／设备状态 | status_word / status | 32000/32089 | UINT16，原始值 |
| 发电／停机／待机 | generating / stopped / standby | 32000 | BOOL，bit1/bit7/bit0 |
| 有功／无功模式 | active_mode / reactive_mode | 35300/35304 | UINT16，原始值 |
| 最后有功／无功指令地址 | active_command / reactive_command | 35303/35307 | UINT16，原始值 |

采集功能码为 0x03。32 位电流与功率按 HL/AB 解析。每台每工况执行 slaveSim 前采样、上位机采集点采样和 slaveSim 后采样。前后源值稳定且为实际新刷新时，逐点核对地址、功能码、数值、品质和采集时间。数值变化的点要求采集时间更新。设备状态枚举、状态字与工况固定目标也分别核对。

全部 147 项设备工况、2646 项逐点匹配及两端关键截图完整才可判定全部抄通。默认每台每工况观察时限 300 秒。采样保存于 huawei-samples-*.json，结果汇总见 huawei-fleet-results.json 和 huawei-fleet-results.md。DSP 在线配置保存、写点配置、DSP 下发调节和 104 遥控未验证。
