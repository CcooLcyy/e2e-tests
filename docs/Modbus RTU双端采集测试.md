# Modbus RTU 双端采集测试

测试只在 DSP 上位机界面查看已运行的 RTU 链路和点值，在 slaveSim 查看实际寄存器反馈。环境准备见 [RTU 模拟环境与观察配置](RTU运行时模拟器配置.md)。

## 用例与固定验收值

| 用例 | 观察条件和期望 |
| --- | --- |
| 连接与点表保存后重读 | 在线保存会修改下位机。当前缺少符合测试边界的保存入口，保留原用例并报告前置条件未满足。 |
| 初始采集 | 第一站原始值 1234，上位机显示 1234、正常品质和有效采集时间。 |
| 变化跟随 | 第一站原始值先为 1234，随后为 2345。上位机两次值均匹配，后一次采集时间更新。 |
| 工程量换算 | 使用预置倍率 0.1、偏移 2 的点，原始值 1234 和 2345 分别对应上位机工程量 125.4 和 236.5，变化后采集时间更新。 |
| 多站隔离 | 两站初始值为 1234 和 4321，第一站变为 2345 时第二站仍为 4321，并确认两站采集继续更新。 |

测试前独立安排每项用例的初始状态和后续观测时序。初始值和后续值应分别保持到对应两端采样结束。RTU 用例只等待观察结果，超时或未出现预定状态保留失败和现场证据。

默认采集时限为 300 秒，工程量绝对误差为 0.000001。记录总线、串口、站号、功能码、地址、Tag、倍率、偏移和两端观察。用例结束只关闭本次观察会话。
