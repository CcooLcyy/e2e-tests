# slaveSim 管理页地址

## 已确认范围

在测试环境中统一设置 slaveSim 管理页地址，保存后重开测试上位机自动回填；提供“打开管理页”，用系统默认浏览器访问所填地址。

## 行为与验收

- 地址为可选项，旧配置和地址留空均兼容现有测试。
- 使用完整的 HTTP 或 HTTPS 地址，例如 `http://192.168.1.100:8080`。校验失败时显示中文错误，不打开其他协议或本机文件。
- 支持反向代理子路径，例如 `https://example.com/slavesim/`，状态接口使用该子路径下的 `api/state`；地址不包含查询参数、页面锚点或账号密码。
- “打开管理页”和“检查连接”使用输入框当前地址，不要求先保存整个环境；更改后需点击“保存环境”才能在下次打开时保留。
- “检查连接”只读访问该地址下的 slaveSim 状态接口，并检查响应格式；连接失败、超时或响应不符时明确显示失败。检查期间禁用重复操作。
- 空地址禁用打开和检查按钮。测试执行期间沿用环境配置锁定规则。
- 地址随环境保存、导入及任务环境记录保留，未来业务用例可以共用。
- 打开浏览器仅表示已请求系统打开，连接检查仅表示状态接口可访问，均不代表 DSP 控制业务通过。

本次不新增 DSP/slaveSim 业务用例，不自动监控页面、修改模拟器值或配置，不改动被测系统。框架自测使用本地模拟响应验证保存兼容性、地址校验、浏览器调用和连接错误；前端检查及桌面构建验证接入。
