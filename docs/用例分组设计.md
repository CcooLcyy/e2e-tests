# 用例一级分组

## 目标与边界

在现有 React/Tauri 测试上位机的用例列表内增加可折叠的一级分组。每个分组是一行标题，其下直接展示该组用例，取消平铺分组卡片。分组只影响展示、定位及勾选，不改变用例标识、断言、失败结果和实际执行顺序，不修改被测 DSP 系统。旧 Tk 界面继续兼容用例发现，不在本次界面改造范围内。

## 用例元数据

通过 `pytest.mark.case_group("分组名称")` 明确声明所属分组。可在文件级使用 `pytestmark` 作为默认分组，单项标记优先于文件级标记。未标记的旧用例归入“未分组”；显式空分组、非法参数或非字符串名称应在发现阶段明确报错，不静默丢弃用例。

当前十一项归为：基础登录三项，密码记忆与自动登录七项，启动与界面一项。分组根据发现顺序首次出现的位置排列；新的分组追加在末尾。用例发现仍保留原有顺序，新用例追加到完整列表末尾。

## 界面与选择

- 默认显示全部分组标题，组内用例收起；点击标题展开或收起该组，支持“全部展开／全部折叠”。标题包含箭头、整组复选框、组名、总数、已选数和通过／失败数。
- 每个分组支持整组选中、取消及半选状态，复选框作用于完整分组，不受搜索条件或折叠状态影响。表头复选框作用于当前搜索结果，折叠不会减少其选择范围；没有匹配项时禁用表头选择。
- 搜索匹配分组名、用例名或说明，只显示包含匹配项的分组并自动展开。搜索期间仍可折叠匹配分组；清空搜索恢复搜索前的展开状态。
- 折叠、展开和搜索不清空选择或结果。刷新用例时保留仍存在用例的选择和分组展开状态，新发现用例默认选中，新分组默认收起，删除的用例和分组状态移除。
- 界面按分组展示，组内用例保留完整列表中的原序号和相对顺序，不重新编号；同组新增用例在该组已有用例之后。
- 实际提交执行的标识始终从原始完整列表按顺序过滤得到，不能根据分组展示、搜索、折叠或勾选顺序重排。运行期间禁止修改选择，允许展开和折叠查看。

## 验收

先验证元数据采集与前端纯逻辑，再接入界面。覆盖默认折叠、逐组和全部展开／折叠、搜索自动展开与清空恢复、跨组保留勾选、半选、空列表、统计、刷新与全局执行顺序。最终运行相关框架自测、前端测试与构建，并以本机界面检查折叠和勾选行为；不执行 DSP 业务登录来替代分组功能验收。
