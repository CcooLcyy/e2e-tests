# 用例一级分组

## 目标与边界

在现有 React/Tauri 测试上位机的用例列表内增加可折叠的一级分组。每个分组是一行标题，其下直接展示该组用例。展示和执行统一采用分组及组内顺序，不改变用例标识、断言或失败结果，不修改被测 DSP 系统。旧 Tk 界面继续兼容用例发现，不在本次界面改造范围内。

## 用例元数据

通过 `pytest.mark.case_group("分组名称")` 明确声明所属分组。可在文件级使用 `pytestmark` 作为默认分组，单项标记优先于文件级标记。未标记的旧用例归入“未分组”；显式空分组、非法参数或非字符串名称应在发现阶段明确报错，不静默丢弃用例。

当前十一项归为：基础登录三项、启动与界面一项、密码记忆与自动登录七项，依次执行。`tests/case-order.json` 是分组及组内顺序清单：新增用例登记到所属组末尾，新分组登记到清单末尾，禁止靠文件命名决定业务执行顺序。旧项目未提供清单时按分组首次发现顺序归组；尚未登记的新用例临时追加到所属组末尾，并记录提示，随后应补齐清单。

发现和执行共用同一排序规则。显式非法清单、重复组名或用例标识、清单分组与实际声明不一致时明确失败，不能悄悄采用另一种顺序。只勾选部分用例时保持清单中的相对顺序，任务记录、实际执行和界面编号保持一致。

## 界面与选择

- 默认显示全部分组标题，组内用例收起；点击标题展开或收起该组，支持“全部展开／全部折叠”。标题包含箭头、整组复选框、组名、总数、已选数和通过／失败数。
- 每个分组支持整组选中、取消及半选状态，复选框作用于完整分组，不受搜索条件或折叠状态影响。表头复选框作用于当前搜索结果，折叠不会减少其选择范围；没有匹配项时禁用表头选择。
- 搜索匹配分组名、用例名或说明，只显示包含匹配项的分组并自动展开。搜索期间仍可折叠匹配分组；清空搜索恢复搜索前的展开状态。
- 折叠、展开和搜索不清空选择或结果。刷新用例时保留仍存在用例的选择和分组展开状态，新发现用例默认选中，新分组默认收起，删除的用例和分组状态移除。
- 界面按分组及组内清单顺序展示并连续编号；同组新增用例在该组已有用例之后。
- 实际提交和执行均按分组及组内顺序过滤出已选用例，不能根据搜索、折叠或勾选先后重排。后端同样校正请求顺序，防止非界面调用打乱分组顺序。运行期间禁止修改选择，允许展开和折叠查看。

## 验收

先验证顺序清单、分组采集及前端纯逻辑，再验证任务执行。覆盖组内新增追加、显式组序及组内序、未登记兼容、非法清单、部分选择、逆序请求及任务记录与实际执行一致。保留折叠、搜索和勾选的回归测试；不执行 DSP 业务登录来替代排序功能验收。
