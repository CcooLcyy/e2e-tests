# RTU 模拟环境与观察配置

本文说明 RTU、华为机群和 104 品质用例如何准备模拟资源。

## 运行前准备

1. 环境页配置已提供的 slaveSim 地址和采集等待时限。测试用例启动独立浏览器，并通过 DSP 上位机已有在线业务入口配置采集。
2. 每条用例先读取模拟配置，有原有总线时在草稿中删除全部总线，再创建本例资源并一次保存应用。配置为空时直接创建。基础 RTU 用例新建单站或双站手动寄存器，确认运行页路径，并记录实际总线、串口、站号和地址。 [基础 RTU 验收](Modbus%20RTU双端采集测试.md)
3. 华为用例在专用模拟器创建六路机群，第 n 路包括站号 1 至 n，并从运行页读取实际串口及配置。 [华为六路采集验收](华为21台六路RTU采集测试.md)

## 运行边界

每条用例在配置生效后读回本例拓扑。进入模拟器准备后，用例结束时清空 slaveSim 的全部总线并读回确认。失败时先留证，再清理。测试上位机按 slaveSim 地址记录从现有总线读到的共享串口目录。遇到空配置时优先沿用该目录，首次连接空配置时使用页面提供的默认目录。104 品质用例在测试阶段保持两条总线的串口路径，通过切换目标从站驱动工况。 [104 品质验收](Modbus%20RTU到104品质验收.md)
