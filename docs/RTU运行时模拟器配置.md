# RTU 模拟环境与观察配置

本文说明基础 RTU 和华为机群用例如何准备模拟资源。

## 运行前准备

1. 环境页配置已提供的 slaveSim 地址和采集等待时限。测试用例启动独立浏览器，并通过 DSP 上位机已有在线业务入口配置采集。
2. 基础用例读取现有模拟配置，复用可恢复的手动寄存器或创建本例资源，确认运行页路径，并记录实际总线、串口、站号和地址。 [基础 RTU 验收](Modbus%20RTU双端采集测试.md)
3. 华为用例在专用模拟器创建六路机群，第 n 路包括站号 1 至 n，并从运行页读取实际串口及配置。 [华为六路采集验收](华为21台六路RTU采集测试.md)

## 运行边界

slaveSim 保存总线配置会重置全部设备运行状态。用例仅在没有无关运行资源时执行全量应用，修改复用点前先记录原值。失败时先留证，再恢复本例修改并按身份清理。 [104 品质验收](Modbus%20RTU到104品质验收.md)
