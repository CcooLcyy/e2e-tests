# RTU 模拟环境与观察配置

## 运行前准备

1. 在测试之外准备已连接并运行的 DSP、串口、slaveSim 总线及模型和对应点表。DSP 上位机启动后须能从正常的 Modbus RTU 页面看到目标设备的预置链路。本地测试上位机的程序路径用于启动 DSP 上位机。
2. 环境页填写实际对接的 slaveSim 页面地址和采集等待时限。测试使用专用平台账号和独立浏览器观察会话。
3. 基础用例将 [基础观察示例](examples/modbus-rtu.example.json) 复制为 `local/modbus-rtu.json`，填写预置总线、串口、两站站号和读保持寄存器零基地址，以及实际 DSP 上位机连接名称和 Tag。另填第一站倍率 0.1、偏移 2 的预置点。倍率测试可和其他用例分开运行，以满足串口占用约束。
4. 华为用例将 [机群观察示例](examples/huawei-rtu.example.json) 复制为 `local/huawei-rtu.json`。按顺序填写六路实际总线名称和串口。第 n 路预置站号 1 至 n；DSP 上位机的连接名称为 `<总线名>-s<站号>`，采集点 Tag 为 `<连接名>-<点标识>`。固定工况和点位见 [华为六路采集验收](华为21台六路RTU采集测试.md)。

## 运行边界

用例通过上位机打开协议业务页面，通过 slaveSim 读取运行反馈。两份专项配置仅声明观察对象。基础用例需要预先安排固定原始值及变化，机群用例需要预先安排七个可观测工况。运行中缺少预置链路、点表、模拟设备或固定工况时保留实际证据并报告失败。用例不会创建、改写或清理下位机及模拟器配置。
