# 错误密码提示测试

## 范围

新增一项真实桌面测试，追加在已有十项用例之后。复用独立副本、专用账号、界面动作及凭据清理能力；不修改测试执行内核、已有用例或被测 DSP 系统。

## 前置条件与操作

1. 使用全新独立副本，以及 `local/login-account.json` 中的专用测试账号。
2. 在本用例内先使用正确密码登录并主动退出，确认账号、密码和平台当前可用。前置登录或退出失败时，本用例失败，并注明尚未进入错误密码验证。
3. 使用同一账号，生成一个非空、长度为 24 的错误密码，并确认其与正确密码不同。记住密码和自动登录均不勾选，只提交一次错误密码，不自动重试。

## 验收标准

- 显示明确的账号或密码错误提示，例如“账号或密码错误，请重新输入”。支持“帐号”“账户”“用户名”等称呼及“密码错误／不正确／有误／不匹配”等明确表述，可附重新输入、重试或重新登录的指引；忽略标点和空格差异。
- “登录失败，请检查账号、密码、账号启用状态及平台连接地址”等泛化提示不符合本项标准；网络错误、会话过多、限流等提示也不能替代错误密码提示。
- 仍停留在登录页，没有进入工作台，登录按钮恢复可操作，账号和密码框可继续编辑。
- 所有条件同时满足才通过。文案不符合要求时，记录实际文案并截图，保持失败，不调整断言、不修改工具或 DSP 系统。

## 证据与清理

记录前置条件、错误密码提交、实际提示及各项断言，截图保持密码掩码。正确和错误密码均不写入步骤、断言信息或报告。结束后复用已有流程关闭本次测试实例并清理本次测试凭据，不清理其他平台会话。
