# 测试通过率

已确认口径：通过率 = 通过数 ÷（通过数 + 失败数）× 100%，保留一位小数。

- 执行页顶部、历史列表和历史详情使用同一口径；执行期间随本次任务结果更新。
- 未执行、运行中、跳过和停止不计入分母，未产生通过或失败结果时显示“—”。
- 例如：8 通过、2 失败、5 未执行，显示 80.0%；全通过显示 100.0%，全失败显示 0.0%。
- 搜索、折叠或重新勾选不改变已经运行任务的统计范围；历史记录按各自任务结果计算，不重写历史文件。
- 完成进度仍按原逻辑独立显示。通过率仅说明已判定结果，通过率 100.0% 不代表全部用例已执行。

验收：检查混合状态、零有效结果、全通过、全失败、小数舍入和任务范围隔离，并核对执行页及历史记录展示一致。按仓库约定不主动运行本地构建或测试，自测由用户按需执行。
