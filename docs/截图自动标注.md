# 截图自动标注

## 目标与边界

采用统一配置、统一渲染、公共操作复用目标、特殊检查按需声明的方式。只修改测试上位机，不修改被测 DSP 系统、业务断言、用例顺序及原始失败证据。

环境增加 `annotation_enabled`，默认开启，旧配置按开启处理；关闭后仅保存原图。颜色、字体和线宽在统一渲染模块集中定义，不在用例中绘图。

## 操作接口

`desktop.step()`、`check()`、`capture()` 接受可选的 `targets` 列表。例如：

```python
targets = [{"locator": (By.CSS_SELECTOR, 'button[type="submit"]'), "label": "点击登录"}]
with desktop.step("点击登录按钮", targets=targets):
    button.click()
```

公共登录操作统一声明账号框、密码框、选项、登录按钮及工作台信息；特殊认证错误检查声明错误提示位置。标注只读取定位和可见区域，不读取或显示输入值；密码说明只描述操作，不含密码。定位失败、目标不唯一、隐藏、越界、页面切换或窗口变化时，不使用旧坐标猜测位置，保留说明与缺失原因。没有目标的步骤只生成文字说明。

## 图片与报告

- 原始 PNG 使用现有名称和采集流程，不覆盖；另存 `*.annotated.png`。
- 标注图在截图下方增加说明区，显示步骤说明、拍摄时步骤判定及编号含义；目标可用时画编号框，失败步骤使用红色。说明区不覆盖原图内容。标记表达操作/检查位置，不能据此推断业务通过。
- 截图记录保留 `name` 作为原图，新增 `annotated_name`、`annotation_status`（`saved` / `failed` / `disabled`）、`annotation_error` 及 `annotations`（目标的 `label`、有效 `rect` 或不可标记原因）。
- JSON/Markdown、当前详情、历史详情及放大预览优先展示标注图，支持查看原图；旧报告沿用原图。桥接仅从当前产物目录安全枚举图片，标注副本不能显示成额外的一条证据。
- 标注失败独立报告原因并退回原图，不影响原业务判定，不掩盖截图失败或原始异常，不补开应用。

## 验收

1. 开关经环境保存、任务快照传到执行端；关闭后不生成标注图，旧环境默认开启。
2. 原图字节不变，标注图存在且包含中文说明；截图无目标也有说明。重复截图互不覆盖。
3. 目标位置按视口与 PNG 实际像素比例映射，覆盖缩放、滚动、部分越界及不可见目标；页面变化不能在新页面沿用旧框。
4. 公共操作自动声明目标，特殊用例可补充；输入值特别是密码不进入新增标注元数据。
5. 标注失败、无法截图、失败步骤、嵌套步骤保持原始业务结果与编号关联。
6. 报告和界面默认标注图、可看原图，历史兼容，不能读取产物范围外图片。

先增加框架自测并观察失败，再实现和回归；使用模拟驱动与生成的示例页面图片，不访问真实账号、平台或设备。完成后进行标注示例图片的人工视觉检查。
